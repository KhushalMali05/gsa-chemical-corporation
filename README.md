# GSA Chemical Corporation — Website Redesign

## Project Goal
Redesign the existing website `https://www.gsachemical.com/` with a completely new visual design (layout, color palette, typography, spacing, UI components) while keeping the content and images sourced only from the existing live website.

## Hard Constraints
- **Tech Stack**: HTML and CSS only. No JavaScript frameworks, no React/Vue, no build tools, no CSS frameworks (no Bootstrap/Tailwind CDN). Plain `.html` files + plain `.css` file(s). Minimal vanilla JS for small interactivity (mobile nav toggle).
- **Static Pages**: Every page built as a separate static `.html` file.
- **Content & Images**: All text content, product names, product descriptions, company details, contact info, and images are sourced directly from live pages on `https://www.gsachemical.com/`.
